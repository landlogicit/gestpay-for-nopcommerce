# Gestpay for nopCommerce v4.30
This plugin allows paying with GestPay Banca Sella for nopCommerce 4.30
Overview
This update adds support for Refund, Capture, and Void operations to the GestPay (Fabrick) plugin for nopCommerce 4.30. These features are implemented using the existing SOAP S2S (Server-to-Server) API, ensuring compatibility with the current infrastructure.
